# portfolio

Minimalist, high-end pixel-inspired portfolio website.

## Run locally

Because this is a static site, you can run it with any local web server from the repository root:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Customize placeholders

Edit `/home/runner/work/portfolio/portfolio/index.html` and replace:

- `[Your Name]`
- `[Your Role / Specialty]`
- `[Project One]`, `[Project Two]`, `[Project Three]`
- contact links and email in the footer

## Files

- `/home/runner/work/portfolio/portfolio/index.html` — page structure and placeholder content
- `/home/runner/work/portfolio/portfolio/styles.css` — minimalist pixel-inspired styling, responsive layout, and focus/hover states
